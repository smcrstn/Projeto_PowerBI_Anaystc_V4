Power BI Financial Analyst | Análise Estratégica de Performance

Este projeto foi desenvolvido como parte do desafio prático da formação **Power BI Analyst** da DIO (Digital Innovation One).

O objetivo foi criar um dashboard interativo e analítico utilizando a base Financials, aplicando conceitos de visualização de dados, storytelling, parâmetros dinâmicos e análise de indicadores financeiros.

---

Objetivos do Projeto

- Desenvolver dashboards interativos no Power BI
- Criar análises financeiras dinâmicas
- Aplicar conceitos de UX e storytelling em BI
- Utilizar parâmetros para análise flexível de dados
- Trabalhar com indicadores financeiros e comerciais

---

Funcionalidades Implementadas

Dashboard Executivo
- Indicadores financeiros principais
- Total de vendas
- Lucro total
- COGS
- Evolução de vendas

Navegação entre páginas
- Botões de navegação personalizados
- Experiência interativa entre dashboards

Análise Estratégica Dinâmica
Página desenvolvida com foco em storytelling e análise executiva.

Recursos:
- Parâmetro dinâmico de categorias:
  - Produto
  - País
  - Segmento
  - Mês

- Parâmetro dinâmico de indicadores:
  - Total Sales
  - Total Profit
  - Total COGS

- Visual dinâmico para análise comparativa

Layout e Design

O projeto utiliza:
- Identidade visual em tons de roxo e violeta
